# WORKER — учебный учёт сотрудников

Консольная программа для технологической практики. Область применения — учебная модель учёта работников кафедры цифровой экономики. Программа не является кадровой системой университета; демонстрационные сотрудники вымышлены.

## Запуск

Требуется .NET SDK 8. В папке проекта:

```sh
dotnet run
dotnet run -- --demo
dotnet run -- --test
```

Первый режим запрашивает количество работников, фамилию и инициалы, должность, зарплату, год приёма и порог стажа. Ввод зарплаты допускает точку или запятую, без разделителей тысяч. Для Windows можно выполнить `run.cmd`.

## Требования задания

- Класс `WORKER` находится в отдельном модуле `Worker.cs`.
- Четыре свойства с закрытыми сеттерами: ФИО, должность, зарплата, год приёма.
- Три конструктора: без аргументов, с двумя аргументами, с четырьмя аргументами.
- Деструктор C# `~WORKER()` включён для соответствия учебному заданию. Это финализатор: он вызывается сборщиком мусора в неопределённый момент. Неуправляемых ресурсов нет, поэтому тело пустое. В промышленном коде такой финализатор следует удалить, а для реальных ресурсов использовать IDisposable.
- Метод Update проверяет все новые данные до изменения объекта. Display выводит поля.
- Коллекция — `List<WORKER>`. Поиск сохраняет исходный порядок и не удаляет однофамильцев.
- Условие отбора: `расчётный год - год приёма > порог`. Равенство не подходит.
- При отсутствии результатов выводится специальное сообщение.

В интерактивном режиме используется текущий системный год. Поскольку задание хранит только год приёма, стаж оценивается по календарным годам, без точности до даты. Для кадрового применения нужны полная дата приёма и более точный расчёт. Демо и тесты фиксируют расчётный год 2026 для воспроизводимости.

## Структура

- `Worker.cs` — модель и поиск;
- `Program.cs` — ввод и вывод, демонстрация;
- `WorkerTests.cs` — 20 проверок без сторонних библиотек;
- `TEST_RESULTS.txt` — результат фактического запуска тестов;
- `DEMO.txt` — результат демонстрационного запуска.

## Пример

Для работников с годами приёма 2018, 2021 и 2024 при расчётном годе 2026 и пороге 5 стаж равен 8, 5 и 2 годам. Программа выводит только фамилию первого работника — Иванов.

## Ограничения и развитие

Данные хранятся в оперативной памяти и теряются после завершения. Следующие этапы: полная дата приёма, сохранение в файл или БД, разграничение доступа, журнал изменений. Наследование не введено, поскольку для всех работников задан одинаковый набор данных и правил. Поиск имеет сложность O(n), дополнительная память результата — O(k).
